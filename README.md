# Вспышка ⚡ — RSVP-ридер для iPhone

Скорочтение по технологии RSVP: слова мелькают по одному, красная буква — точка фокуса (ORP, как в Spritz). Работает как приложение на iPhone (PWA), книги хранятся прямо на телефоне, интернет после установки не нужен.

## Установка на iPhone
1. Открой адрес приложения в **Safari**.
2. **Поделиться → На экран «Домой»**.
3. Запускай с иконки — полноэкранный режим, офлайн.

## Форматы книг
EPUB, FB2, FB2.ZIP, TXT (utf-8 и windows-1251), DOCX, RTF, PDF (с текстовым слоем), HTML, MD.
MOBI/AZW3 (Kindle) и DRM-книги не поддерживаются — конвертируй в EPUB, например в Calibre.

## Перемотка
- ⏮ **предл.** / ⏮ **абзац** — к началу текущего или предыдущего предложения/абзаца;
- **ползунок прогресса** — в любое место книги;
- **☰ главы** — оглавление с переходом;
- **лента недавних слов** — тап по слову продолжает с него.

## Управление
Пауза/продолжить — только кнопкой ▶/⏸. Ползунок скорости 100–900 сл/мин. В настройках: размер слова, тема, длина пауз на пунктуации. На десктопе: пробел — пауза, ←/→ — по предложениям, ↑/↓ — скорость.

## Разработка
Статика без сборки: открой папку любым HTTP-сервером. Тесты парсеров: `node test.mjs` в rsvp-tests (jsdom).
